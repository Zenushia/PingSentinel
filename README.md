## 🚀 About The Project
**PingSentinel** is a lightweight, interactive Python tool designed to monitor the uptime and latency (response time in milliseconds) of user-defined web services and cloud infrastructure.

## ✨ Features
- 🔄 **Interactive Target Selection:** Dynamically input any website or cloud endpoint you want to monitor.
- ⚡ **Real-Time Latency Tracking:** Measures exact response times in milliseconds (`ms`).
- 🟢🔴 **Status Indicators:** Instantly detects whether a service is online (`ONLINE 🟢`) or down (`OFFLINE 🔴`).
- 📦 **Zero Dependencies:** Built entirely with Python standard libraries (`urllib`, `time`).
